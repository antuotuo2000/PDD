先说我的核心判断：

PDD 是一家商业模式非常优秀、竞争优势明显，但长期盈利质量和竞争壁垒仍然存在不确定性的公司。

如果用巴菲特、段永平的价值投资思路分析，我认为它值得研究，但不能简单地因为 PE 低就认为它便宜。

我会重点考察五件事：

  • 拼多多国内业务能否持续保持高利润率？
  • Temu 国际化业务最终能否实现盈利？
  • 商家、消费者和平台之间的利益分配是否可持续？
  • 政策、监管和地缘政治风险是否会改变商业模式？
  • 当前市值是否已经充分反映这些风险？

1\. 拼多多：中国电商

  • 商家支付交易服务相关费用。

  • 连接中国及其他地区供应商与海外消费者。
  • 通过低价商品获取消费者。
  • 通过平台交易、履约及商家服务获得收入。
  • 目前仍需要大量投入物流、营销和本地化建设。

我认为 PDD 最强的三个护城河

第一：低价心智。

消费者已经形成了一个认知：买便宜商品，可以先看看拼多多。

这种用户习惯一旦形成，竞争对手很难通过简单降价完全复制。

第二：算法和流量分发。

拼多多不是完全依靠用户主动搜索商品，而是通过推荐机制让消费者发现商品。

这使得它能够帮助大量中小商家获取订单。

第三：供应链整合能力。

PDD 长期连接大量中小制造商、产业带和消费者。

它有机会减少传统渠道中的中间环节。

不过，我要强调一个问题：

低价不是绝对护城河。

如果商家长期赚不到钱，就可能退出平台；如果商品质量下降，消费者也会流失。

因此，真正值得关注的是平台能否让商家、消费者和平台三方长期获益。

2. Temu 的海外监管风险

这是 PDD 最大的长期不确定性之一。

Temu 面临的挑战包括：

  • 美国小额包裹免税政策变化。
  • 欧盟对商品合规、消费者保护和平台责任的监管。
  • 各国对跨境电商的税收要求。
  • 物流、仓储、退货和本地化成本。
  • 国际贸易政策和地缘政治风险。

尤其值得关注的是，PDD 在2026年年报披露的监管事项中，已经包括欧盟针对 Temu 的调查、美国多个州的诉讼，以及 FTC 相关合规事项。

2026年4月，中国市场监管部门还对拼多多运营主体处以约15亿元人民币罚款，并采取了部分商家入驻限制措施。

这些都不是可以忽略的小风险。

3. 商家生态问题

PDD 的商业模式很依赖商家。

如果平台过度追求低价，可能出现：

  • 商家利润持续下降。
  • 商品质量不稳定。
  • 商家减少投入。
  • 优质品牌不愿意长期经营。
  • 平台不得不投入更多补贴。

这会影响平台长期的商业价值。
